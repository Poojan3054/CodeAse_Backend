# CodeAse Backend

CodeAse Backend is a Node.js and Express-based backend for a coding learning platform.  
It handles user authentication, course management, quizzes, and results.

---

## Features
- User registration and login with JWT authentication
- Admin panel to manage courses, quizzes, and users
- RESTful APIs for courses, quizzes, and results
- Secure password handling with bcrypt

---

## Tech Stack
- Node.js
- Express.js
- MongoDB with Mongoose
- JWT for authentication
- bcrypt for password hashing
